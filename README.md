# Computational Neuroscience Coursework Repository

This repository is a collection of computational neuroscience course work from two Columbia courses, organized by course, homework, and projects.

## What is in this repo

- Jupyter notebooks (`.ipynb`) containing code, simulations, figures, and written responses.
- PDF files (`.pdf`) that are mostly assignment handouts and/or exported assignment writeups.
- Work focused on neural circuit modeling, time encoding machines (TEM/IAF/ASDM), filter identification, ON/OFF pathways, and model-neuron I/O characterization.

## Folder overview

### `BMEBW4020 Comp Neuro Circuits in the Brain`

Coursework from BMEB W4020, organized into:

- `hw1` through `hw6`
- `project1`
- `project2`

Contents include homework/project notebooks and corresponding PDFs for several assignments.

### `ECBM4070E Computing with Brain Circuits of Model Organisms`

Coursework from ECBM E4070/E6070, organized into:

- `hw2`
- `hw3`
- `hw4`
- `project1`

Contents include homework/project notebooks, assignment PDFs, and a reference research paper PDF used in project work.

## Notes on the PDFs

- Several PDFs are assignment handouts (problem statements and instructions).
- Several PDFs appear to be exported versions of completed notebook submissions.

  - `A_Directionally_Selective_Small_Target_Motion_Detecting_Visual_Neural_Network_in_Cluttered_Backgrounds.pdf`

## Intended use

This repo is intended as a portfolio-style archive of computational neuroscience practice across homework and project assignments, with both implementation notebooks and supporting course/reference documents.
